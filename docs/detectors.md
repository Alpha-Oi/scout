# Детекторы

Scout запускает до 14 детекторов по очереди. Каждый независим: если инструмента
нет, детектор **пропускается и это пишется в `scan.log`**, находки не выдумываются.
Статус на вашей машине показывает `python tools/doctor.py --check`.

> Большинство детекторов ориентированы на **Python-проекты**. Два встроенных
> (`secrets`, `todo-fixme`) читают текстовые файлы на любых языках
> (JS/TS, Go, Rust, Java, Ruby и т. д.).

| Детектор | Категория | Что ищет | Нужен | Совет, что делать |
|---|---|---|---|---|
| `pytest-failed` | bug | падающие тесты | `pytest` | `pytest --lf -v`, смотреть traceback |
| `pip-audit` | vuln | известные CVE в зависимостях | `pip-audit` | обновить пакет до исправленной версии |
| `pip-outdated` | improvement | устаревшие зависимости (без CVE) | `pip` | обновлять планово, не срочно |
| `bandit` | vuln | `eval`, `subprocess` с shell, слабая криптография | `bandit` | заменить опасный вызов |
| `ruff` | bug / improvement | неопределённые имена, неиспользуемые импорты, стиль | `ruff` | часто лечится `ruff check --fix` |
| `mypy` | bug | ошибки типов: `None`, атрибуты, аргументы | `mypy` | исправить типы или логику |
| `vulture` | improvement | мёртвый код | `vulture` | удалить, но проверьте динамические вызовы |
| `radon` | improvement | цикломатическая сложность > 10 | `radon` | разбить функцию |
| `interrogate` | improvement | функции без docstring | `interrogate` | дописать, либо понизить severity |
| `pyscn` | improvement | клоны кода | `uv` (`pyscn`) | вынести общее |
| `semgrep` | vuln | SAST по готовым правилам | `semgrep` | разбирать по правилу |
| `detect-secrets` | vuln | секреты по энтропии | `detect-secrets` | проверить, потом ротировать |
| `todo-fixme` | incomplete | `TODO` / `FIXME` / `XXX` / `HACK` | встроен | реализовать или удалить |
| `secrets` | vuln | ключи, токены, пароли по regex | встроен | см. ниже |

## Особенности отдельных детекторов

| Детектор | Что нужно знать |
|---|---|
| `semgrep` | Запускается с `--config auto`: **скачивает правила с semgrep.dev и требует включённых метрик** (с `--metrics off` semgrep отказывается работать). Без доступа к сети детектор молча даёт 0 находок (в `scan.log` будет пометка), а ожидание может занять минуты. В закрытых контурах отключите его: `"skip_detectors": ["semgrep"]` |
| `interrogate` | Берёт файлы с покрытием docstring ниже 80%. Пустые `__init__.py` не считаются. Читает сводную таблицу `interrogate -v`: машинного вывода у инструмента нет |
| `pytest-failed` | Запускает тесты проекта текущим Python (`python -m pytest`), а не `pytest` из `PATH`. `doctor.py` ставит `pytest` именно туда |
| `pyscn` | Ставится через `uv` (`python -m uv tool install pyscn`). Может создавать `.pyscn/` в проекте |
| `pip-audit` | Берёт зависимости из `requirements.txt`, а если его нет, из `pyproject.toml`; без обоих файлов пропускается |
| `pip-outdated` | Читает **только** `requirements.txt` (список пакетов проекта), а версии сверяет с **текущим окружением Python**, в котором запущен Scout. Без `requirements.txt` пропускается |
| `secrets`, `detect-secrets` | Значение секрета в отчёт не попадает: `secrets` пишет `[REDACTED]`, `detect-secrets` показывает только префикс хэша |

## Если Scout нашёл секрет

1. Проверьте evidence: это настоящий ключ или заглушка из примера/теста?
2. Настоящий: **сначала отозвать и выпустить новый** у провайдера. Удаление из кода
   не помогает, ключ остался в git-истории.
3. Вынести значение в переменную окружения или `.env`, а `.env` добавить в `.gitignore`.
4. Заглушка: переименуйте или вынесите в тестовые данные, чтобы детектор не срабатывал.

## Что Scout игнорирует

- Служебные каталоги: `.git`, `node_modules`, `.venv`, `venv`, `__pycache__`,
  `dist`, `build`, `.mypy_cache`, `.ruff_cache`, `.pyscn`, `.scout` и другие.
- Слишком большие файлы и нетекстовые расширения.

## Как добавить свой детектор

Детектор это функция `detect_<имя>(project, log)` в `tools/scan.py`, возвращающая
список находок в [едином формате](../README.ru.md#формат-находки). Правило проекта:
**нет инструмента, нет находок**; ничего не выдумывать.
