# Scout

Когда пользователь пишет /scout <путь> или просит "просканируй проект",
загрузи .claude/skills/scout/SKILL.md и следуй фазам по порядку.

## Как читать

Один файл фазы за раз, в момент старта фазы. Не открывай все сразу.
Файл для каждой фазы указан в таблице роутера в SKILL.md.

## Runtime

Инструменты - Python-скрипты в tools/. Они одинаково работают на
Windows, macOS и Linux. Не переписывай их - вызывай.

## Границы

Scout только читает проект. Пишет - только в каталог отчётов
(по умолчанию ./.scout). Никаких коммитов, пушей и правок.
